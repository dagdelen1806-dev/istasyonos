- KVKK güvenlik rehberi PDF açıldı: https://www.kvkk.gov.tr/yayinlar/veri_guvenligi_rehberi.pdf . Yetki/log, şahsi cihaz riskleri, şifreleme/anahtar ayrımı, bulut sağlayıcı tedbirlerini değerlendirme. Rehber belirli AES bit boyunu kanun hükmü diye tanımlamaz. Veri güvenliği web sayfası browser’da timeout oldu; PDF metni elde edildi.
- OWASP dosya yükleme fetch + browser: https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html . MIME’a güvenmeme, tip/içerik doğrulama, sandbox, kaynak sınırı, yeniden encode/metadata temizliği; antivirüs/CDR hizmetine veri sızdırmama. Yeniden encode tek başına tüm riskleri kaldırmaz.
- OWASP cryptographic storage açıldı: https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html . Anahtar/veri ayrımı, bağımsız DEK/KEK, rotation/restore; şifreleme erişim kontrolünün yerine geçmez.
- Cloud Vision OCR bölge belgesi açıldı: https://docs.cloud.google.com/vision/docs/ocr . Varsayılan global yer garantisi yok; eu-vision.googleapis.com + locations/eu OCR bölgesel işleme. Türkiye lokasyonu değildir.
- Cloud Vision data usage FAQ açıldı: https://cloud.google.com/vision/docs/data-usage . Online BatchAnnotateImages/Files görüntüleri memory’de, diskte persist yok; offline async kısa süre saklama ve birkaç saat failsafe TTL; geçici request metadata logları. İçerik Vision model eğitiminde kullanılmıyor. Bu FAQ tüm bulut/log/kendi bucket saklama davranışının yerine geçmez; KVKK aktarım hukuki mekanizması sağlamaz.
